# 管理后台

管理后台位于 `/admin`，仅启用状态的管理员可访问。

## 管理员从哪来

- 首次运行：没有任何账号时，用启动日志里的 `dropit setup code` 在 `/setup` 创建第一个管理员；或用 `ADMIN_EMAIL` / `ADMIN_PASSWORD` 在空库启动时直接创建。
- 用户表为空时，第一个成功 OAuth 登录的身份也会成为管理员（事务保证并发时只有一个）——仅当 OAuth 已通过环境变量配置时可能发生，不需要初始化码。
- `ADMIN_EMAILS` 中的邮箱之后经 OAuth（provider 验证邮箱）注册时也会成为管理员；密码注册不受它影响，总是普通用户。
- 管理员可以把其他用户设为管理员；最后一个启用的管理员不能被禁用或降级。

## 用户

![管理 → 用户](https://raw.githubusercontent.com/lthero-big/dropit/main/docs/screenshots/admin-users.png)

- **预创建**：按邮箱创建待激活账号（可指定角色和配额），该邮箱第一次经 provider 验证的 OAuth 登录会绑定到此账号。勾选「生成临时密码」时会显示一次临时密码，对方用它登录即激活，并被要求立即改密码。
- **重置密码**：在用户编辑里点「重置密码」，生成一次性显示的临时密码，同时让对方所有设备下线；对方下次登录必须先改密码（期间浏览器会话只能改密码或退出）。用户列表显示每人的登录方式（密码 / GitHub / Google）。
- **命令行重置**：管理员自己也忘了密码时，`docker exec dropit dropit-admin reset-password <邮箱>` 直接改库并打印临时密码；`dropit-admin list-users` 列出账号。
- **禁用 / 启用**：禁用立即吊销该用户所有会话和 WebSocket。
- **登录设备**：在用户编辑里查看该用户的登录设备（浏览器 · 系统 · IP 网段 · 最近活动），可单独登出某台设备。
- **强制下线（全部设备）**：删除该用户所有会话，账号保持启用，可重新登录。
- **配额**：为单个用户设置覆盖值，或恢复安装默认值。
- 邮箱不可修改；不同 provider 的身份不会按邮箱自动合并。

## 注册策略

「管理 → 注册」决定谁能创建新账号，对密码注册和 OAuth 首次登录都生效：

- **仅邀请**（默认）：需要有效的邀请链接，或管理员预创建了该邮箱的账号。邀请链接可以用 OAuth 或「设置密码注册」。
- **关闭**：不接受新账号；已有账号照常登录。
- **开放**：任何人都能用邮箱 + 密码或 OAuth 注册（普通用户）。密码注册**不验证邮箱**，别人可以抢先占用某个邮箱；公网实例建议保持仅邀请。

## 邀请

- 选择目标空间、可用次数（1–100）和有效期（1–720 小时）生成邀请链接 `/invite/<token>`。
- 令牌只在创建时返回一次，数据库只存 SHA-256；可随时撤销。

## 注册邀请（仅管理员）

- 只有管理员能邀请别人注册：「管理 → 邀请」类型选「注册邀请」，设置可用次数和有效期，不限数量。对方只得到自己的账号和私人空间，不会加入任何空间。
- 普通用户不能生成注册邀请（`/api/me/invites` 和 `POST /api/admin/invites` 对他们返回 403）。他们只能在「设置 → 空间成员」邀请已有账号的人加入自己的空间；这种邀请不能注册新账号。
- 在用户编辑里可以逐个用户修改「空间邀请上限」（同时有效的空间邀请数；留空 = 默认 5，0 = 不能邀请；管理员不受限）。
- 「邀请」列表显示所有邀请（类型、创建者和状态），管理员可以撤销。旧版本里普通用户生成的注册邀请会标成「普通用户创建，已不能注册」。注册策略为「关闭」时注册邀请也不能注册。

## 个人访问令牌

- 管理员可查看并吊销所有用户的令牌；用户自己在 `/settings` 管理。

## 运行时限额

![管理 → 限制](https://raw.githubusercontent.com/lthero-big/dropit/main/docs/screenshots/admin-limits.png)

- 后台限额编辑器展示每项的当前值、环境默认值、是否覆盖以及上下界。
- 修改整体校验、原子提交，并写入审计记录（分页查看）。详细规则见 [配置](Configuration.md#运行时覆盖)。

## 站点地址

- 「管理 → 站点地址」显示当前生效的地址及来源（页面设置 / 环境变量 / 按访问地址自动），以及 Cookie 是否 Secure、是否信任反代。
- 输入只能是 协议 + 域名或 IP + 端口（如 `https://dropit.example.com`、`http://192.168.1.10:8787`），不能带路径；保存后立即生效，优先于环境变量 `APP_ORIGIN`。「清除页面设置」恢复环境变量或自动模式。
- 新地址与当前访问地址不同时需要确认；保存后请用新地址访问。改错进不去时用 `RESET_APP_ORIGIN=1` 启动一次。
- 页面列出 GitHub / Google 的 OAuth 回调地址，可直接复制到 provider 后台。

## 版本与更新

- 「管理 → 更新」显示当前版本、git 短 hash、构建时间和部署方式（Docker 镜像 / compose 本地构建 / 源码）。
- 服务端默认每 12 小时检查 Docker Hub 或 GitHub 是否有新版本，结果缓存；可以「立即检查」（60 秒内重复点击复用上次结果）。
- 有新版本时，管理页和设置页顶部提示，并给出与部署方式匹配的升级命令（可复制）。服务端不会自己升级；需要全自动时见 [部署 → 自动更新](Deployment.md#自动更新可选)。
- 离线部署设 `UPDATE_CHECK=false`。
