## 主要特性

<CardGrid>
  <Card title="剪贴板" icon="document">
    文本 / 文件条目、实时同步、就地编辑、Markdown 安全渲染、标签、置顶、分组、来源设备、命令面板。
  </Card>
  <Card title="文件" icon="seti:image">
    WebP 缩略图与预览、视频/音频内联播放、`Range` 断点下载、分片续传上传。
  </Card>
  <Card title="分享与临时房间" icon="external">
    有时限、可限次、可撤销的只读链接；无需账号的临时房间（≤ 24 小时，二维码加入）。
  </Card>
  <Card title="账号" icon="github">
    邮箱 + 密码与 GitHub / Google OAuth、首次运行 /setup 初始化码、注册策略（默认仅邀请）、管理员重置密码、个人访问令牌、设备码登录。
  </Card>
  <Card title="管理" icon="setting">
    用户、邀请、令牌、运行时限额（即时生效 + 审计）。
  </Card>
  <Card title="运维" icon="rocket">
    单进程 Node + SQLite（WAL）+ 本地磁盘；单 Docker 镜像；`/healthz`。
  </Card>
</CardGrid>
