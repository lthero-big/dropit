## Features

<CardGrid>
  <Card title="Clipboard" icon="document">
    Text / file items, real-time sync, in-place editing, safe Markdown rendering, tags, pinning, groups, source device, command palette.
  </Card>
  <Card title="Files" icon="seti:image">
    WebP thumbnails and previews, inline video/audio playback, resumable `Range` downloads, resumable chunked uploads.
  </Card>
  <Card title="Sharing and temporary rooms" icon="external">
    Read-only links that can expire, be view-limited and be revoked; account-free temporary rooms (≤ 24 hours, join by QR code).
  </Card>
  <Card title="Accounts" icon="github">
    Email + password and GitHub / Google OAuth, first-run /setup code, registration policy (invite-only by default), admin password reset, personal access tokens, device-code login.
  </Card>
  <Card title="Administration" icon="setting">
    Users, invitations, tokens, runtime limits (applied instantly + audited).
  </Card>
  <Card title="Operations" icon="rocket">
    Single Node process + SQLite (WAL) + local disk; a single Docker image; `/healthz`.
  </Card>
</CardGrid>
